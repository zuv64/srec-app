# sRec

某S社の録画・視聴支援アプリが2027年3月にS-OUTとなることに伴ってつくった代替アプリです。

お手持ちのレコーダー・テレビと同じLAN（Wi-Fi）内で使えます。

※このアプリはスマホと機器が同じWi-Fiに接続されている必要があります。外出先からは利用できません。

## できること

- **番組表を見る**：地上波/BS/CSの番組表を表示します。見たい地域を選んで絞り込めます。
- **録画予約の一覧を見る**：レコーダーに登録されている録画予約を確認できます。
- **録画番組の一覧を見る**：レコーダーとテレビ（USB/HDD）に録画されている番組をまとめて確認できます。
  - 同じシリーズの番組はまとめて表示され、タップで展開できます。
  - 録画の削除はレコーダーの番組のみ可能です（テレビの録画はこのアプリからは削除できません）。
  - 削除前には必ず確認画面が出ます。

## 使えない機能

以下は著作権保護技術（DTCP-IP）の制約により、このアプリでは対応していません。

- 外出先からの視聴・録画予約
- 家の中の別室での視聴（モバイル視聴）
- 録画番組のスマホへの転送

## はじめかた

1. アプリを起動し、「設定」画面からレコーダー・テレビを検出します。
2. 検出された機器をタップして登録します。
   - テレビを登録する場合はPIN入力が必要です。テレビの画面に表示されるPINコードを入力してください。
3. 「番組表」画面で見たい地域を選択します。
4. 「録画一覧」画面でレコーダー・テレビの録画番組をまとめて確認できます。

## 動作環境

- Android 9.0 以降
- レコーダー・テレビと同じLAN（Wi-Fi）内であること

## 注意事項

- 本アプリは個人利用を目的とした非公式のアプリです。SONY公式のサポートはありません。
- レコーダー・テレビの機種によっては動作しない場合があります。

## 対応機器

下記機器で動作確認しています。下記機器の商標はソニー株式会社に帰属します。

- ブルーレイディスクレコーダー: **BDZ-FBT6100**
- テレビ: **KJ-55X9000F**（BRAVIA、USB/HDD録画対応）
